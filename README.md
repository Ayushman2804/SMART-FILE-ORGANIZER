# Smart File Organizer (Python)

An advanced Python automation tool that organizes files into categories like Images, Documents, Videos, and more.

## Features
- Organizes files automatically based on extensions
- Handles duplicate filenames intelligently
- Creates folders dynamically
- Logs all operations to a file
- Simple CLI interface

## Technologies Used
- Python
- os module
- shutil module

## How to Run
1. Clone the repository
2. Run the script:
   python smart_file_organizer.py
3. Enter the folder path when prompted

## Example
Input: Mixed files in Downloads folder  
Output: Files sorted into categorized folders
